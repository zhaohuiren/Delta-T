## 2. 视觉规范

### 2.1 风格

- Android 原生简洁的 Material 3 深色界面。
- 页面背景使用近黑色；内容用 16dp 左右圆角卡片承载。
- 删除大面积切角、赛车海报式装饰、无意义英文标题和重复功能入口。
- 中文优先，仅保留 `PB`、`GAP`、`P1`、`S1`、`S2`、`S3` 等必要术语。
- 主要操作保持足够触控面积；驾驶中的实时页只保留无需频繁点击的信息。

### 2.2 颜色语义

| 颜色 | 建议色值 | 唯一语义 |
|---|---:|---|
| 紫色 | `#B05CFF` | 本月最快 / 严格快于月参考 |
| 绿色 | `#38E86B` | 本周最快 / 严格快于周参考 / GNSS 良好 |
| 黄色 | `#FFC247` | 慢于当前有效参考 |
| 灰色 | 中性灰阶 | 持平、没有可比较参考、未开始、无效或辅助信息 |
| 红色 | `#FF1E2D` | 主操作、实时状态、危险/删除行为 |

颜色不能作为唯一信息载体，必须同时显示“本月最快”“本周最快”“慢于本月”“本周首条记录”等文字。月、周状态互相独立，允许同一成绩同时显示紫色和绿色标签。

### 2.3 排版与适配

- 关键计时数字使用等宽数字特性，避免跳动。
- 正文最小字号目标 14sp，关键辅助文字不低于 12sp。
- 以 360dp 宽度为最低适配目标；排行榜分段信息允许两行，但不允许横向裁切核心成绩。
- 底部导航固定为：首页、历史、纪录、设置。
- 实时计时页不显示底部导航，减少误触和视觉干扰。

## 3. 页面精确规则

### 3.1 首页

- “上班”“下班”卡片分别直达对应路线编辑，因此不再显示单独的“管理路线与计时点”按钮。
- 两个方向分别计算本周最快与最近一次，禁止跨方向计算差值。
- “一键准备”仍是首要操作，副文案为“自动识别上班或下班路线”。
- 首页 v3 不再使用大面积红色按钮；主操作改为炭黑色准备卡配中等尺寸红色启动按钮。
- 两条路线放入一个统一容器，以分隔线组织，减少厚重卡片和后台面板感。

### 3.2 实时计时

- 月比较与周比较分两行展示，不用单一颜色覆盖两套结果。
- 实时结果只能写“有望本周最佳 · 实时估算”，不可提前写成已确认纪录。
- 动态容差仅用于实时防闪烁，不改变完成后的严格成绩规则。

### 3.3 完成结果

- 已完成且质量 A/B 的成绩，只要严格更快即为纪录。
- 没有周纪录但存在月纪录时，总成绩可显示“本周首条记录”，分段仍退回月参考进行比较。
- 示例中的 S1/S2/S3 均慢于月参考，因此必须显示黄色，不能显示灰色。

### 3.4 历史列表

- 按发生时间展示全部记录，包括质量 C、无效和中断记录。
- “本月最快”“本周最快”是根据当前历史动态计算的标签，可同时出现。
- 删除放入次级菜单，避免红色垃圾桶抢占列表视觉焦点。

### 3.5 单次详情

- 月差、周差分别显示颜色和语义；例如 S2 可以同时为“慢于本月”和“本周最快”。
- 高德地图只负责显示；路线点和计时仍使用原始 WGS84 数据。
- 地图中的点位顺序在实现时严格为 `A → S1 → S2 → B`。设计图的底图和路线仅是视觉示意，不作为真实地理数据。
- 不显示“设为固定基准”及当前固定基准文案。

### 3.6 F1 排行榜

- 按当前方向汇总全部历史有效 A/B 成绩，总时间升序排列为 P1、P2……。
- 相同总时间按日期、ID 稳定排序。
- P1 用字号、位置和 `PB` 标签突出，不用整行紫色填充。
- GAP 为相对 P1 的时间差；P1 显示 `LEADER`。
- 每行显示总时间、S1/S2/S3、日期和质量；当前月/周标签可同时出现。
- 理论最佳为当前计时点版本下，三个全历史最快有效分段之和。
- 质量 C、无效和中断记录不进入排行榜，只留在历史页。

## 5. 设计确认后的实施验收点

1. 代码实现逐屏与本目录设计稿对照，但业务含义以本文精确规则为准。
2. API 36 模拟器截图必须覆盖六个页面和空状态。
3. 成绩规则、v3 回填、路线源轨迹保护、排行榜查询必须有自动测试。
4. AMap Debug 必须通过单测、Lint、编译、安装和启动冒烟测试。
5. 最终交付 APK、SHA-256、版本信息、自测报告和代码 Review 报告。

## 6. 生成方式与 Prompt 摘要

六张图片均使用 OpenAI ImageGen，以现有对应页面截图作为“问题/内容参考”，按照 `ui-mockup` 类型重新生成；不是在旧截图上直接涂改。各图 Prompt 重点分别为：

1. 首页：路线卡兼管理入口、方向数据独立、删除重复按钮。
2. 实时：月周双比较、估算措辞、三分段状态与路线图。
3. 完成：周为空时回退月参考、慢分段黄色。
4. 历史：全记录、双标签、异常状态、弱化删除。
5. 详情：高德底图、月周独立分段颜色、无固定基准。
6. 纪录：全历史 F1 排名、PB/GAP/三分段、无日历。
